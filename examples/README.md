# arXiv Scraper API – code examples

Examples for every arXiv endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/paper.sh`](curl/paper.sh) | `bash paper.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/paper.php`](php/paper.php) | `php paper.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/Paper.cs`](csharp/Paper.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/paper.go`](go/paper.go) | `go run paper.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/PaperExample.java`](java/PaperExample.java) | `java PaperExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/paper.rb`](ruby/paper.rb) | `ruby paper.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/paper.mjs`](nodejs/paper.mjs) | `node paper.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
